# 📂 Manipulação de Vetores (Arrays)

Pasta destinada aos exercícios, algoritmos e mini-projetos focados em **manipulação de vetores (arrays)**, desenvolvidos durante as disciplinas de programação (2º período de Sistemas de Informação - UFU).

## 🎯 Objetivo
Praticar a lógica de programação de baixo nível, o gerenciamento de índices e o uso intensivo de **aritmética de ponteiros e alocação de memória** na linguagem C, consolidando a base necessária para Estrutura de Dados.

## 📁 Conteúdo da Pasta
Aqui você encontrará códigos que resolvem problemas clássicos, tais como:
* Rotacionamento de elementos (direita/esquerda)
* Inversão de vetores
* Buscas e ordenações básicas
* Operações matemáticas e manipulação de tamanhos fixos/dinâmicos

## ⚙️ Como compilar e executar

Como os códigos são escritos em **C**, você pode usar o `gcc` (ou qualquer outro compilador de sua preferência) pelo terminal:

1. Entre na pasta do exercício desejado:
   ```bash
   cd nome-da-pasta-do-exercicio

2. Compile o código:
   gcc nome_do_arquivo.c -o programa

3. Execute:
   # No Linux/macOS
./programa

# No Windows (Prompt de Comando / PowerShell)
.\programa.exe
